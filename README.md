# گردول — نسخه وب (GitHub Pages)

بازسازی کامل وب‌اپلیکیشن ورزشی و تغذیه **گردول** با هوش مصنوعی شخصی هر کاربر.

## ✨ ویژگی‌ها

- 🔑 **ورود اجباری با کلید API شخصی** (رایگان از [Google AI Studio](https://aistudio.google.com/app/apikey))
- 👁️ **چشم گردول** — شمارش واقعی تکرارها و کنترل فرم بدن با دوربین (MediaPipe Pose، اجرای ۱۰۰٪ روی دستگاه کاربر) برای **تمام ۱۴۱ حرکت**
- 🤖 **مربی هوشمند** — چت با حافظه، آگاه از پرونده بدنی شما، با قابلیت تحلیل عکس
- 📸 **ثبت غذا با عکس یا متن** — تحلیل کالری و ماکرو غذاهای ایرانی با بینایی ماشین
- 🔄 **جایگزینی تمرین و غذا** — پیشنهادهای استاندارد + پیشنهاد هوشمند AI
- ⏱️ **پلیر جلسه تمرین** — ویدیوی اصلی هر حرکت + تایمر + بوق + استراحت خودکار
- 🎯 **روز رسیدن به هدف** — پیش‌بینی تاریخ شمسی با فرمول بالینی Mifflin-St Jeor
- 🔔 **نوتیفیکیشن‌ها** — یادآور تمرین، آب، ثبت شام و هشدار استریک
- 💧 آب · ⚖️ وزن · ⏳ فستینگ ۱۶:۸ · 🛒 لیست خرید · 💾 بکاپ کامل JSON

## 🔒 امنیت و حریم خصوصی (اولویت اول)

- **بدون سرور**: کل اپ استاتیک است؛ هیچ بک‌اندی وجود ندارد.
- **داده‌ها فقط روی دستگاه شما**: پروفایل، لاگ‌ها، چت و عکس‌ها فقط در `localStorage` مرورگر خودتان ذخیره می‌شوند و هرگز جایی ارسال نمی‌شوند.
- **کلید API فقط به گوگل می‌رود**: تنها اتصال شبکه خارجی به `generativelanguage.googleapis.com` (سرور رسمی Google) با کلید خود شماست.
- **CSP سخت‌گیرانه**: منابع فقط از همین دامنه؛ اسکریپت خارجی، آنالیتیکس و تبلیغ ممنوع.
- **دوربین هرگز آپلود نمی‌شود**: فریم‌های چشم گردول فقط در RAM پردازش می‌شوند.
- **خروجی AI همیشه escape می‌شود**: ضد XSS.
- **پاک‌سازی کامل**: از تنظیمات، همه داده‌ها با یک کلیک حذف می‌شوند.

## 🚀 اجرا

فقط `index.html` را روی هر هاست استاتیک (GitHub Pages) باز کنید. برای تست لوکال:

```bash
npx serve .
# یا
python -m http.server 8080
```

## 📁 ساختار

```
index.html            — پوسته اپ + CSP
css/style.css         — تم تاریک گردول (فونت وزیرمتن لوکال)
js/app.js             — موتور اصلی (تب‌ها، آنبوردینگ، لاگ‌ها، نوتیفیکیشن، بکاپ)
js/gemini.js          — کلاینت امن هوش مصنوعی
js/pose-engine.js     — چشم گردول (MediaPipe + قوانین فرم ۱۴۱ حرکت)
js/exercises-data.js  — بانک ۱۴۱ حرکت با ویدیو (داده اورجینال)
js/plans-data.js      — ۵ برنامه ۳۰ روزه (داده اورجینال)
js/meals-data.js      — برنامه غذایی روزانه ایرانی (داده اورجینال)
js/grocery-data.js    — لیست خرید هفتگی (داده اورجینال)
assets/mediapipe/     — موتور بینایی لوکال (بدون CDN)
assets/fonts/         — فونت وزیرمتن لوکال
videos/               — ۲۸۷ ویدیوی تمرینی اورجینال
```
